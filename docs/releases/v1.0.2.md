# zscalerctl v1.0.2

A release-packaging fix. Commands, flags, output, schemas, exit codes and
redaction are unchanged.

## Release artifacts

- The cosign bundle for `SHA256SUMS` is now `SHA256SUMS.sigstore.json`, the
  standard Sigstore bundle name; v1.0.1 and earlier call it
  `SHA256SUMS.bundle`. Scripts that verify releases need the new name in
  `cosign verify-blob --bundle`. See Verify Release Artifacts in
  [INSTALL.md](https://github.com/dvmrry/zscalerctl/blob/v1.0.2/docs/INSTALL.md).
- The binaries' Go build info (`go version -m`) now reports `v1.0.2` with
  `vcs.modified=false`. v1.0.0 and v1.0.1 reported `+dirty` because the
  release job left untracked files in its checkout; their source matched the
  tag, and `zscalerctl version` was correct.
