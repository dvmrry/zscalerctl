# zscalerctl v1.0.1

A maintenance release: a newer Go toolchain and dependency updates. Commands,
flags, output, schemas, exit codes and redaction are unchanged.

## Toolchain

- Built with Go 1.27.3 (v1.0.0 used 1.26.10). Source builds now need Go
  1.27.3 or newer.
- The macOS builds need macOS 13 Ventura or later. The Linux builds stay
  static and run on kernel 3.2 or later, so RHEL 7 and later work.
- On macOS and Windows, setting `SSL_CERT_FILE` or `SSL_CERT_DIR` now replaces
  the system certificate store: only the roots in those files are trusted.
  If you set them for a TLS-inspection root, keep public roots in the bundle
  as well, or unset them for `zscalerctl`. `GODEBUG=x509sslcertoverrideplatform=0`
  restores the system store. See TLS Inspection in
  [INSTALL.md](https://github.com/dvmrry/zscalerctl/blob/v1.0.1/docs/INSTALL.md).

## Dependencies

- `charm.land/lipgloss/v2` v2.0.6, `github.com/spf13/pflag` v1.0.10 and
  `golang.org/x/sys` v0.49.0, with their indirect updates.
- Release SBOMs are generated with `cyclonedx-gomod` v1.12.0.
